cloudflare有api可以讓我用程式查d1 kv  r2等的使用量？

---

是的，Cloudflare 現在有提供專門的 API 讓你可以用程式查詢各項服務的使用量。

Cloudflare 在 **2026 年 8 月**正式推出了全新的 **Billable Usage API**。這是一個專門為了自動化、開發者以及 FinOps 團隊設計的單一端點，你可以透過它一次查詢包含 **D1、R2、Workers KV、Vectorize、Workers AI** 等所有基於用量計費的產品數據。

## Billable Usage API 的特點

* **單一端點查詢**：不需要為 D1、R2、KV 分別呼叫不同的 API，一次請求就會回傳帳號下所有產品的用量與成本拆分。
* **標準化格式**：輸出的欄位格式對齊了 FinOps 的 FOCUS (FinOps Open Cost and Usage Specification) 標準，非常適合用程式進行後續解析。
* **時間區間篩選**：支援傳入 `from` 與 `to` 參數來查詢特定日期的用量。

---

## 如何使用程式查詢

要使用這個 API，你需要在 Cloudflare 控制台中建立一個具有 **Billing Read** (帳單讀取) 權限的 API Token。

### cURL 呼叫範例

```bash
# 查詢當前計費週期的總使用量
curl "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/billable-usage" \
-H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"

# 查詢特定時間區間的使用量
curl "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/billable-usage?from=2026-02-01&to=2026-02-15" \
-H "Authorization: Bearer $CLOUDFLARE_API_TOKEN"

```

### 回傳資料結構 (JSON)

API 會回傳一個陣列，每一筆資料代表一項產品（例如 D1 或 R2）在特定計費週期的狀態，關鍵欄位包含：

* `ServiceName` / `ServiceFamilyName`：產品名稱（例如 "R2 Storage" 或 "Workers Standard"）
* `PricingQuantity` / `ConsumedUnit`：使用的數量與單位（如 GB-months, requests）
* `ContractedCost`：該週期的費用
* `CumulatedPricingQuantity`：該計費週期的累計使用量

> **補充說明**：如果你的需求**不是**為了看計費/帳單，而是想要分析非常細微的請求量、快取命中率或網路流量分佈，Cloudflare 另外還有提供 **GraphQL Analytics API**。但若單純是要看 D1 / KV / R2 額度用掉多少，用 Billable Usage API 是最直接且準確的做法。
